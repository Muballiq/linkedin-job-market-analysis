# LinkedIn Job Market Analysis

## Project Overview
This project analyzes LinkedIn job postings to understand job market trends, identify in-demand skills, and explore job opportunities across different locations in India.

## Objectives
- Collect job posting information.
- Extract job titles, company names, locations, and required skills.
- Clean and preprocess job data using Pandas.
- Identify frequently requested skills and job roles.
- Visualize skill demand across different locations.

## Technologies Used
- Python
- Pandas
- Requests
- BeautifulSoup
- Regular Expressions
- Seaborn
- Matplotlib
- Microsoft Excel
- Microsoft Power BI

## Project Workflow
1. Collect job posting data.
2. Extract job details and descriptions.
3. Identify skills using regular expressions.
4. Clean the dataset and remove duplicate records.
5. Export the processed dataset to Excel.
6. Analyze job roles and skill demand.
7. Visualize the results using charts and a heatmap.

## Project Files

- `dashboard.pbix` — Power BI dashboard.
